# The Meeting That Should Have Been One Line

One sentence that could have replaced an entire pointless meeting:

> Nobody in this room has new information, nobody here can approve anything, and the decision was already made in the email none of you read.

It kills the meeting in three strokes: no new information, no one who can decide anything, and a decision already made in an email nobody read. After this line, there is no reason left to hold the meeting at all.

## Run

Requires Node 22 or later. No dependencies, no network, no secrets.

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`. To write elsewhere (for local testing), set `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/out node main.ts
```
